## Why Extract?

### 1. Different Core Missions

**AgentScope:**
- Parse `.claude/settings.json`
- Scan `.claude/skills/`, `.claude/agents/`
- Visualize agent architectures
- Document Claude Code setups

**DevContainer Scanner:**
- Parse `.devcontainer/devcontainer.json`
- Security scanning (DREAD, secrets, container escape)
- Lifecycle orchestration
- Feature dependency analysis

**Overlap:** Near zero

### 2. Different Target Users

**AgentScope:**
- Claude Code users
- Agent developers
- Teams using swarms/MCP

**DevContainer Scanner:**
- DevOps engineers
- Security teams
- **Any** developer using DevContainers (not just Claude)

**Overlap:** Claude Code users who also use DevContainers

### 3. Standalone Value

**DevContainer Scanner** can exist independently:
- Security tool for any project with `.devcontainer/`
- CI/CD integration for container security
- GitHub Action for PR checks
- NPM package: `@devcontainer/scanner`

**AgentScope** benefits:
- Clearer focus on agent scanning
- Simpler codebase
- Can optionally integrate DevContainer Scanner if needed

import { scanDevContainer } from '@devcontainer/scanner';

export async function scanComplete(rootPath: string) {
  const agentScan = await scanAgentScope('.claude');

  // Optional: Also scan DevContainer if present
  const hasDevContainer = fs.existsSync('.devcontainer/devcontainer.json');
  const devContainerScan = hasDevContainer

## Benefits Analysis

### For AgentScope

| Benefit | Impact |
|---------|--------|
| **Focused Mission** | Users know exactly what AgentScope does: agent scanning |
| **Simpler Codebase** | No container security complexity to maintain |
| **Clearer Documentation** | Agent-specific docs, no mixing with containers |
| **Faster Development** | No context switching between agent/container concerns |

### For DevContainer Scanner

| Benefit | Impact |
|---------|--------|
| **Broader Adoption** | Any project with DevContainers can use it |
| **Dedicated Development** | Container security focus without agent concerns |
| **Standalone Value** | Security tool useful on its own |
| **Clear Identity** | "DevContainer security scanner" vs "Agent + Container tool" |

### For Both

| Benefit | Impact |
|---------|--------|
| **Separation of Concerns** | Each project does one thing well |
| **Independent Versioning** | Release at different cadences |
| **Optional Integration** | AgentScope can import DevContainer Scanner if needed |
| **Broader Reach** | Two focused tools > one unfocused tool |
