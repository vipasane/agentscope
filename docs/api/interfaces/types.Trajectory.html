    Interface Trajectory

    Learning trajectory

    Records a complete execution path for learning purposes. Used by ReasoningBank to extract patterns and improve future decisions.

    Example

    {
      id: 'traj-123',
      task: 'implement-auth-feature',
      steps: [...],
      outcome: 'success',
      reward: 0.85,
      duration: 5000
    }
    interface Trajectory {
