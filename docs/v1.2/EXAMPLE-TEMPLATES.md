## Template 3: Dataflow Diagram Structure

```markdown
# Data Flow Diagram

[← Back to Overview](./README.md)

---

## System Data Flow

\`\`\`mermaid
graph LR
    subgraph Sources["📥 Data Sources"]
        User[User Input<br/><small>CLI commands</small>]
        Config[Config Files<br/><small>.claude/, .mcp.json</small>]
        MCP[MCP Servers<br/><small>External tools</small>]
    end

    subgraph Transformations["🔄 Transformations"]
        Parse[Parser<br/><small>JSON/YAML → Types</small>]
        Validate[Validator<br/><small>Types → Validated</small>]
        Generate[Generator<br/><small>Validated → Output</small>]
    end

    subgraph Sinks["📤 Outputs"]
        Docs[Documentation<br/><small>README.md, categories/*.md</small>]
        Diagrams[Diagrams<br/><small>*.md with Mermaid</small>]
        JSON[Raw Config<br/><small>config.json</small>]
    end

    Config -->|JSON/YAML| Parse
    MCP -->|MCP Protocol| Parse
    Parse -->|AgentScopeConfig| Validate
    Validate -->|ValidatedConfig| Generate
    Generate -->|Markdown| Docs
    Generate -->|Mermaid| Diagrams
    Generate -->|JSON| JSON

    User -.->|Scan command| Parse

    classDef source fill:#e3f2fd,stroke:#1565c0
    classDef transform fill:#fff8e1,stroke:#f9a825
    classDef sink fill:#e8f5e9,stroke:#1b5e20
    class User,Config,MCP source
    class Parse,Validate,Generate transform
    class Docs,Diagrams,JSON sink
\`\`\`

---

## Data Format Annotations

| From | To | Format | Transformation |
|------|-----|--------|---------------|
| Config Files | Parser | JSON/YAML | Parse frontmatter |
| Parser | Validator | TypeScript Types | Type checking |
| Validator | Generator | Validated Config | Sanitization |
| Generator | Docs | Markdown | Template rendering |
| Generator | Diagrams | Mermaid | Diagram generation |

---

[← Back to Overview](./README.md)
```
