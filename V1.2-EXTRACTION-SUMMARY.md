## Why Separate?

### 1. Different Missions

| AgentScope | DevContainer Scanner |
|------------|---------------------|
| Parse `.claude/` configs | Parse `.devcontainer/` configs |
| Visualize agent architectures | Scan container security |
| Document Claude Code setups | Lifecycle orchestration |
| Agent-specific | Universal (any project) |

### 2. Different Users

| AgentScope | DevContainer Scanner |
|------------|---------------------|
| Claude Code users | All DevContainer users |
| Agent developers | DevOps engineers |
| Swarm/MCP teams | Security teams |

### 3. Standalone Value

**DevContainer Scanner** is valuable on its own:
- Security tool for any project with `.devcontainer/`
- CI/CD integration for container security
- GitHub Action for PR checks
- Not tied to Claude/agents

**AgentScope** benefits:
- Clearer focus: "Agent configuration documentation"
- Simpler codebase
- Can optionally integrate DevContainer Scanner

## Integration Example (Optional)

AgentScope can optionally integrate DevContainer Scanner:

```typescript
// Install as dependency
npm install @devcontainer/scanner

// Use in code
import { scanDevContainer } from '@devcontainer/scanner';

const agentScan = await scanAgentScope('.claude');
const containerScan = await scanDevContainer('.devcontainer');

const fullReport = {
  agents: agentScan,
  devcontainer: containerScan
};
```
