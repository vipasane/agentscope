## Decision Criteria

### Extract if:
- ✅ File parses `.devcontainer/` (YES → EXTRACT)
- ✅ Container security focused (YES → EXTRACT)
- ✅ Universal container value (YES → EXTRACT)
- ✅ No agent references (YES → EXTRACT)

### Keep if:
- ✅ File parses `.claude/` (YES → KEEP)
- ✅ Agent configuration focused (YES → KEEP)
- ✅ Claude-specific (YES → KEEP)
- ✅ Agent visualization (YES → KEEP)
